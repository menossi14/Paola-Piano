PAOLA PIANO — VERSÃO 0.5 INSTALÁVEL (PWA)

IMPORTANTE: descompactar o ZIP e abrir index.html direto (file://) NÃO habilita instalação PWA. Publique os arquivos mantendo a estrutura em uma hospedagem HTTPS (ex.: GitHub Pages, Netlify ou Cloudflare Pages).

NO ANDROID:
1. Abra o endereço HTTPS do site no Chrome.
2. Aguarde a opção “Instalar aplicativo” no próprio Paola Piano, ou toque no menu ⋮ do Chrome e selecione “Instalar app”/“Adicionar à tela inicial”, conforme a versão do Chrome.
3. Confirme. O ícone Paola Piano aparecerá na tela inicial, e o aplicativo abrirá sem a barra usual do navegador, quando instalado como PWA.

O modo offline permite carregar a interface já visitada. Renderização completa de MusicXML pode depender de conexão pois a biblioteca de notação está em CDN. A biblioteca local permanece vinculada à origem HTTPS instalada e não é migrada automaticamente de file:// ou de outro domínio.
